# Customer_Behaviour_Analysis
Analyzes 3,900+ transactions to uncover insights on spending patterns, customer segments, and product trends. Built using Python, PostgreSQL, and Power BI, delivering actionable insights on revenue, discounts, and subscription behavior.

# PROBLEM STATEMENT
A retail company aims to understand changing customer purchasing patterns across demographics, products, and sales channels. The goal is to identify key factors influencing buying decisions and use these insights to improve engagement, sales, and long-term loyalty.

# PROJECT OVERVIEW
This project analyzes 3,900+ customer transactions to uncover insights into spending behavior, product preferences, and customer segments.
The workflow integrates:
Python → Data cleaning & feature engineering
PostgreSQL → Business analysis using SQL
Power BI → Interactive dashboard & visualization

# DATA SUMMARY
3,900 rows, 18 columns
Includes:
Customer demographics (age, gender, location, subscription status)
Purchase details (category, amount, season, size, color)
Behavioral metrics (discounts, frequency, ratings, shipping type)
Missing values handled using category-based imputation

# PROJECT WORKFLOW
1. DATA PREPARATION (PYTHON)
Data cleaning and preprocessing
Handling missing values
Feature engineering (age groups, purchase frequency)
Data consistency checks
Loaded processed data into PostgreSQL

2. DATA ANALYSIS (SQL)
Key business insights:
Revenue by gender
High-spending discount users
Top-rated products
Shipping type impact
Subscriber vs non-subscriber comparison
Customer segmentation (New, Returning, Loyal)
Revenue by age group

3. DASHBOARD (POWER BI)
Interactive visualizations of trends and KPIs
Enables quick business decision-making

# TECH STACK
Python (Pandas, Data Cleaning)
PostgreSQL (SQL Analysis)
Power BI (Visualization)
