# Customer Behavior Analysis

Analyzes 3,900+ transactions to uncover insights on spending patterns, customer segments, and product trends. Built using Python, PostgreSQL, and Power BI to deliver actionable insights on revenue, discounts, and subscription behavior.

---

## Key Insights
- Loyal customers contribute a significant share of total revenue  
- Discounts increase purchase volume but may impact profitability  
- Subscribers show higher average spending than non-subscribers  
- Certain age groups and shipping preferences drive higher revenue  
- Top-rated products strongly correlate with frequent purchases  

---

## Problem Statement
A retail company aims to understand changing customer purchasing patterns across demographics, products, and sales channels. The objective is to identify key factors influencing buying decisions and leverage these insights to improve engagement, sales, and long-term customer loyalty.

---

## Project Overview
This project analyzes 3,900+ customer transactions to uncover insights into spending behavior, product preferences, and customer segmentation.

**Workflow:**
- **Python** → Data cleaning & feature engineering  
- **PostgreSQL** → Business analysis using SQL  
- **Power BI** → Interactive dashboard & visualization  

---

## Data Summary
- **Rows:** 3,900  
- **Columns:** 18  

**Includes:**
- Customer demographics (age, gender, location, subscription status)  
- Purchase details (category, amount, season, size, color)  
- Behavioral metrics (discounts, frequency, ratings, shipping type)  

Missing values handled using category-based imputation.

---

## Project Workflow

### 1. Data Preparation (Python)
- Data cleaning and preprocessing  
- Handling missing values  
- Feature engineering (age groups, purchase frequency)  
- Data consistency checks  
- Loaded processed data into PostgreSQL  

### 2. Data Analysis (SQL)
- Revenue by gender  
- High-spending discount users  
- Top-rated products  
- Shipping type impact  
- Subscriber vs non-subscriber comparison  
- Customer segmentation (New, Returning, Loyal)  
- Revenue by age group  

### 3. Dashboard (Power BI)
- Interactive visualizations of trends and KPIs  
- Enables data-driven decision-making
